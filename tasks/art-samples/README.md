# Art samples — drop generated PNGs here

Put raw Ideogram output in this folder and I can measure it: sample the corners,
quantify how flat the background actually is, run the hue-based key + local
de-matte, and show the cut-out composited on both a white and a navy tile.

Chat-attached images do NOT reach the filesystem, so they have to land here (or
anywhere else under the repo) before any of that is possible.

Keep the ORIGINAL file — full resolution, straight from Ideogram, no crop and no
background already removed. The whole point is to measure what the generator
really produced.

Naming: `<subject>-<n>.png`, e.g. `basketball-1.png`. Nothing depends on the
name; it just makes the report readable.
